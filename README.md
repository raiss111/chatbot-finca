# Chatbot Finca.cd

Un assistant intelligent capable de répondre à toutes les questions sur l'organisation Finca en République Démocratique du Congo, en se basant uniquement sur le contenu officiel de leur site web.

## Fonctionnalités

- **Recherche intelligente** : Index inversé avec scoring par fréquence des mots
- **Cache progressif** : Le bot apprend au fil des questions de l'utilisateur
- **Interface moderne** : Application web construite avec Streamlit
- **IA intégrée** : Réponses générées par Llama 3 via l'API Groq
- **Sources vérifiables** : Chaque réponse inclut les liens vers les pages consultées

## ️ Technologies utilisées

- Python 3.13
- Streamlit (Interface graphique)
- BeautifulSoup4 (Parsing HTML)
- Groq API (Intelligence Artificielle)
- Requests (Requêtes HTTP)
